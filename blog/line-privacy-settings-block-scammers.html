คำตอบสั้น: เปิดแอป LINE ไปที่แท็บ "หน้าหลัก" แตะไอคอนรูปเฟือง (ตั้งค่า) แล้วทำ 4 อย่างนี้ก่อน: (1) เมนู "เพื่อน" ปิด "อนุญาตให้เพิ่มเป็นเพื่อน" เพื่อไม่ให้คนที่ได้เบอร์เราไปค้นหาเจอ (2) เมนู "โปรไฟล์" ปิด "อนุญาตให้เพิ่มเพื่อนด้วย ID" (3) เมนู "ความเป็นส่วนตัว" เปิด "ล็อครหัสผ่าน" (4) เมนู "บัญชี" ลงทะเบียนอีเมลกับรหัสผ่าน และตรวจดูอุปกรณ์ที่เข้าสู่ระบบอยู่ ใช้เวลาไม่ถึง 10 นาที แต่ช่วยตัดช่องทางที่มิจฉาชีพใช้เข้าหาเราได้มาก

บทความนี้เป็นคู่มือแบบ "ป้องกันก่อน" สำหรับคนที่ยังไม่เคยโดนอะไร และอยากปิดประตูไว้ก่อน ถ้าคุณเจอกรณีที่บัญชีเพื่อนโดนแฮกแล้วทักมายืมเงิน หรือบัญชีของตัวเองโดนยึดไปแล้ว ให้อ่านบทความเรื่องบัญชีโดนแฮกแล้วยืมเงินแทน ซึ่งเน้นการกู้คืนและการเช็คก่อนโอน

ชื่อเมนูในบทความนี้อ้างอิงจากหน้าช่วยเหลือภาษาไทยของ LINE และข้อมูลจากหน่วยงานที่เผยแพร่ ณ ช่วงเวลาที่เขียน LINE ปรับหน้าตาแอปเป็นระยะ ชื่อเมนูหรือตำแหน่งจึงอาจต่างกันเล็กน้อยตามเวอร์ชัน ระบบ iPhone หรือ Android และภาษาที่ตั้งไว้ ถ้าหาไม่เจอ ให้ใช้ช่องค้นหาด้านบนของหน้าตั้งค่า แล้วพิมพ์คำสำคัญ เช่น "เพื่อน" "ID" หรือ "รหัสผ่าน"

ทำไมการตั้งค่า LINE ถึงสำคัญกับการกันมิจฉาชีพ

LINE เป็นแอปแชทที่คนไทยแทบทุกบ้านใช้ จึงเป็นช่องทางที่มิจฉาชีพอยากเข้าถึงมากที่สุดช่องทางหนึ่ง จุดที่หลายคนไม่รู้คือ ค่าเริ่มต้นของแอปบางอย่างเปิดโอกาสให้คนที่มีแค่เบอร์โทรศัพท์ของเรา ค้นหาเราเจอและทักแชทมาได้เลย ทั้งที่เราไม่เคยรู้จักเขา

ลองนึกภาพว่าเบอร์มือถือของเราหลุดไปอยู่ในรายชื่อที่ซื้อขายกัน ซึ่งเกิดขึ้นได้จากการกรอกเบอร์ลงแบบฟอร์มชิงรางวัล ลงทะเบียนร้านค้า หรือข้อมูลรั่วจากที่ใดที่หนึ่ง คนที่ได้รายชื่อนั้นไปสามารถไล่ใส่เบอร์ในช่องค้นหาเพื่อน แล้วส่งข้อความหาทุกบัญชีที่เจอ โดยตั้งรูปโปรไฟล์เป็นโลโก้หน่วยงาน เจ้าหน้าที่ในเครื่องแบบ หรือคนหน้าตาดีเพื่อชวนคุย

สำนักงานตำรวจไซเบอร์ (บช.สอท.) เคยออกคำเตือนในทำนองเดียวกันว่า มิจฉาชีพใช้แค่เบอร์โทรศัพท์ก็เพิ่มเพื่อนและเริ่มแชทได้ และแนะนำให้ปิดการเพิ่มเพื่อนด้วยเบอร์และด้วย ID ซึ่งเป็นสองขั้นตอนแรกในคู่มือนี้

การตั้งค่าไม่ได้กันการหลอกได้ทุกแบบ เพราะมิจฉาชีพยังเข้าหาเราผ่านกลุ่ม ลิงก์ หรือบัญชีเพื่อนที่โดนแฮกได้ แต่จะลดจำนวน "คนแปลกหน้าที่ทักมาเอง" ลงได้มาก และทำให้ข้อความแปลกปลอมโดดเด่นจนสังเกตง่ายขึ้น

ขั้นที่ 1: ปิดการเพิ่มเพื่อนด้วยเบอร์โทรศัพท์

นี่คือการตั้งค่าที่สำคัญที่สุดสำหรับคนที่ไม่อยากให้คนแปลกหน้าค้นเจอจากเบอร์ ต้องทำบนมือถือเครื่องหลักที่ลงทะเบียนบัญชี LINE ไว้เท่านั้น

  1. เปิด LINE แล้วแตะแท็บ หน้าหลัก
  2. แตะไอคอน รูปเฟือง (ตั้งค่า) มุมขวาบน
  3. เลือก เพื่อน
  4. ปิดสวิตช์ อนุญาตให้เพิ่มเป็นเพื่อน

หลังปิดแล้ว คนที่พิมพ์เบอร์เราในช่องค้นหาเพื่อนจะหาเราไม่เจอ เพื่อนที่มีอยู่แล้วยังคุยกันได้ตามปกติ ถ้าวันหลังอยากให้คนรู้จักใหม่เพิ่มเรา ให้ใช้คิวอาร์โค้ดแสดงต่อหน้าแทน

ในหน้าเดียวกันมีอีกตัวเลือกที่ควรรู้จัก คือ "เพิ่มเพื่อนอัตโนมัติ" ตัวนี้ทำงานกลับด้าน คือให้ LINE ดึงเบอร์จากสมุดโทรศัพท์ของเราไปเพิ่มคนที่ใช้ LINE เป็นเพื่อนให้เอง ข้อเสียคือ เบอร์ที่เราบันทึกไว้ทุกเบอร์ รวมถึงเบอร์ช่าง เบอร์ร้านค้า หรือเบอร์ที่ไม่ได้ติดต่อกันนานแล้ว จะกลายเป็นเพื่อนใน LINE ทั้งหมด ถ้าคุณไม่ต้องการแบบนั้น ให้ปิดไว้ แล้วเพิ่มเพื่อนเองทีละคน

ขั้นที่ 2: ปิดการเพิ่มเพื่อนด้วย LINE ID

LINE ID คือชื่อผู้ใช้ที่ตั้งไว้ให้คนอื่นค้นหา หลายคนตั้งเป็นชื่อเล่นตามด้วยปีเกิดหรือเบอร์โทร ซึ่งเดาง่าย และ ID ที่ตั้งแล้วจะเปลี่ยนหรือลบไม่ได้ ทางที่ดีคือปิดไม่ให้คนค้นด้วย ID

  1. แท็บ หน้าหลัก แล้วแตะไอคอน รูปเฟือง
  2. เลือก โปรไฟล์
  3. ปิดสวิตช์ อนุญาตให้เพิ่มเพื่อนด้วย ID

ถ้าใช้ LINE บนคอมพิวเตอร์ Windows หรือ Mac ก็มีตัวเลือกเดียวกันในหน้าตั้งค่า หมวดความเป็นส่วนตัว ส่วน LINE บน iPad และแท็บเล็ต Android ที่เป็นอุปกรณ์เสริมจะไม่มีตัวเลือกนี้ ให้ตั้งจากมือถือเครื่องหลัก

ข้อควรรู้: ถ้าคุณขายของออนไลน์และต้องให้ลูกค้าแอดด้วย ID การปิดอาจไม่เหมาะ ทางเลือกคือแยกบัญชีส่วนตัวกับบัญชีร้านออกจากกัน แล้วปิดการค้นหาในบัญชีส่วนตัวไว้

ขั้นที่ 3: จัดการคิวอาร์โค้ดและลิงก์เพิ่มเพื่อนที่เคยแชร์ไป

คิวอาร์โค้ดและลิงก์เพิ่มเพื่อนของเราใช้ได้กับทุกคนที่ได้มันไป ไม่ว่าเราจะปิดการค้นหาด้วยเบอร์และ ID แล้วหรือไม่ ถ้าเคยโพสต์คิวอาร์โค้ดลงโซเชียลมีเดีย ส่งในกลุ่มใหญ่ หรือแปะไว้หน้าร้าน ให้ "โหลดใหม่" เพื่อให้โค้ดเดิมใช้ไม่ได้

  1. แท็บ แชท แล้วแตะไอคอน เครื่องหมายบวก ด้านบน
  2. เลือก คิวอาร์โค้ดของฉัน
  3. แตะ โหลดใหม่

ตำแหน่งเมนูนี้อาจต่างไปในบางเวอร์ชันหรือบนแท็บเล็ต ซึ่งอาจอยู่ในปุ่มเพิ่มเพื่อนที่แท็บหน้าหลัก แล้วเลือกคิวอาร์โค้ด หลักง่ายๆ คือ อย่าส่งรูปคิวอาร์โค้ดของตัวเองให้คนที่ไม่รู้จัก ถ้าต้องการเพิ่มเพื่อนกับคนที่เพิ่งเจอ ให้เขาสแกนจากหน้าจอเราต่อหน้า

ขั้นที่ 4: คัดกรองข้อความจากคนที่ไม่ใช่เพื่อน

LINE เวอร์ชันใหม่จะแยกข้อความจากคนที่ไม่ได้เป็นเพื่อนกับเราไว้ในส่วนคำขอแชท แทนที่จะปนอยู่ในรายการแชทปกติ เราจึงเห็นได้ทันทีว่าข้อความไหนมาจากคนแปลกหน้า และเลือกได้ว่าจะเพิ่มเป็นเพื่อน บล็อก ปิดการแจ้งเตือน หรือลบทิ้ง

คำเชิญเข้ากลุ่มจากคนที่ไม่ใช่เพื่อนก็จะมาอยู่ในส่วนนี้เช่นกัน และเราเลือกตอบรับหรือปฏิเสธได้ ส่วนการตั้งค่าว่าจะให้ส่วนคำขอนี้แสดงในรายการแชทหรือไม่ อยู่ในหน้า ความเป็นส่วนตัว ในหมวดเกี่ยวกับการคัดกรองข้อความ ชื่อตัวเลือกอาจแตกต่างกันตามเวอร์ชัน

คำแนะนำ: อย่าซ่อนส่วนคำขอนี้ไว้ทั้งหมด ให้เปิดดูเป็นระยะแล้วลบหรือบล็อกบัญชีที่ไม่รู้จัก เหตุผลคือบางครั้งคนรู้จักจริงที่เปลี่ยนเครื่องหรือเพิ่งได้เบอร์เราก็จะมาอยู่ในส่วนนี้ การเปิดดูเองช่วยให้เราตัดสินใจได้ แทนที่จะพลาดข้อความสำคัญ

ฟีเจอร์นี้อาจยังไม่มีในเวอร์ชันเก่าหรือบน LINE สำหรับคอมพิวเตอร์ที่เป็นอุปกรณ์เสริม ถ้าไม่เห็น ให้อัปเดตแอปจาก App Store หรือ Google Play ก่อน

ขั้นที่ 5: ล็อครหัสผ่านตัวแอป

ล็อครหัสผ่านคือการตั้งรหัสเพื่อเปิดแอป LINE แยกจากรหัสปลดล็อกโทรศัพท์ มีประโยชน์เมื่อมือถือหาย ถูกยืมไปใช้ หรือมีคนแอบหยิบเครื่องไปตอนที่หน้าจอยังไม่ล็อก เพราะคนอื่นจะเปิดอ่านแชทหรือส่งข้อความในนามเราไม่ได้ทันที

  1. แท็บ หน้าหลัก แตะ รูปเฟือง
  2. เลือก ความเป็นส่วนตัว
  3. เปิด ล็อครหัสผ่าน แล้วใส่รหัสที่ต้องการ 2 ครั้ง

ถ้าเครื่องตั้งสแกนใบหน้าหรือลายนิ้วมือไว้ อาจมีตัวเลือกให้ใช้ปลดล็อก LINE ได้ด้วย

คำเตือนสำคัญ: ตามหน้าช่วยเหลือของ LINE ถ้าลืมรหัสนี้ ต้องลบแอปแล้วติดตั้งใหม่ และประวัติแชทที่ยังไม่ได้สำรองไว้จะหายไป ก่อนเปิดล็อครหัสผ่าน ให้สำรองประวัติแชทก่อน และถ้าตั้งให้พ่อแม่ ให้จดรหัสเก็บไว้ในที่ที่ปลอดภัยด้วย ไม่ควรใช้วันเกิดหรือเลขเรียงกัน

ขั้นที่ 6: ลงทะเบียนอีเมล รหัสผ่าน และตรวจอุปกรณ์ที่เข้าสู่ระบบ

ขั้นนี้ไม่ได้กันคนแปลกหน้าทักมา แต่ช่วยให้บัญชีของเรา "กู้คืนได้" ถ้าเปลี่ยนเครื่องหรือมีปัญหา และช่วยให้รู้ตัวถ้ามีคนอื่นเข้าบัญชีเราอยู่

  • รหัสผ่าน: ไปที่ หน้าหลัก > รูปเฟือง > บัญชี ถ้ายังไม่ได้ลงทะเบียนรหัสผ่าน ให้ทำตามขั้นตอนบนหน้าจอ ใช้รหัสที่ยาวพอและผสมตัวอักษรพิมพ์ใหญ่ พิมพ์เล็ก ตัวเลข และสัญลักษณ์ ไม่ใช้ซ้ำกับบัญชีอื่น อ่านหลักการตั้งรหัสที่ดีได้ในบทความเรื่องรหัสผ่านและการยืนยันตัวตนสองขั้นตอน
  • อีเมล: ในหน้า บัญชี เลือก อีเมล ใส่อีเมลแล้วยืนยันด้วยรหัสหรือลิงก์ที่ส่งไป ควรเป็นอีเมลที่เรายังเข้าใช้ได้จริงและตั้งรหัสผ่านแข็งแรง
  • อุปกรณ์ที่เข้าสู่ระบบ: ในหน้า บัญชี จะมีส่วนที่แสดงรายการอุปกรณ์ที่เข้าสู่ระบบด้วยบัญชีของเรา เช่น คอมพิวเตอร์หรือแท็บเล็ต ถ้าเห็นอุปกรณ์ที่ไม่รู้จัก ให้กดออกจากระบบอุปกรณ์นั้นทันที แล้วเปลี่ยนรหัสผ่าน

นิสัยที่ควรมีคู่กันคือ ไม่บอกรหัสยืนยันที่ส่งมาทาง SMS กับใครเด็ดขาด แม้คนนั้นจะอ้างว่าส่งผิดเบอร์หรือเป็นเจ้าหน้าที่ เพราะรหัสนั้นอาจเป็นกุญแจย้ายบัญชีของเราไปเครื่องอื่น (ดูเพิ่มเติมเรื่องซิมโดนสวม รับ OTP แทน)

ดูให้เป็น: บัญชีทางการ กับบัญชีที่แอบอ้าง

มิจฉาชีพชอบตั้งบัญชีที่ใช้ชื่อและโลโก้คล้ายธนาคาร หน่วยงานรัฐ หรือบริษัทขนส่ง แล้วทักไปหาผู้ใช้ก่อน ข้อสังเกตที่ใช้ได้จริงมีดังนี้

  • ดูโล่หน้าชื่อบัญชี: บัญชีทางการที่ผ่านการรับรองจาก LINE จะมีโล่สีน้ำเงินหรือสีเขียว ส่วนโล่สีเทาหมายถึงบัญชีทั่วไปที่ยังไม่ผ่านการรับรอง ใครก็สมัครได้ ถ้าบัญชีที่อ้างเป็นองค์กรใหญ่มีโล่สีเทา ให้ระวังเป็นพิเศษ
  • ใครเป็นฝ่ายเริ่ม: โดยทั่วไป เราต้องเป็นคนเพิ่มบัญชีทางการเป็นเพื่อนเอง ถ้ามีบัญชีที่อ้างเป็นองค์กรทักมาหาเราก่อนแบบไม่ได้ขอ ให้ถือว่าน่าสงสัย
  • จำนวนเพื่อน: บัญชีขององค์กรใหญ่มักมีผู้ติดตามจำนวนมาก บัญชีที่เพิ่งสร้างมักมีน้อยผิดปกติ
  • สิ่งที่ขอ: ถ้าบัญชีไหนขอให้โอนเงิน ขอรหัส OTP ขอเลขบัตร หรือส่งลิงก์ให้ติดตั้งแอป ให้หยุดทันที ไม่ว่าจะมีโล่หรือไม่ (ดูแอปดูดเงิน ควบคุมเครื่องระยะไกล)
  • หาทางเข้าเอง: วิธีที่ปลอดภัยที่สุดคือเข้าบัญชีทางการผ่านลิงก์บนเว็บไซต์ขององค์กรนั้น หรือเบอร์หลังบัตร ไม่ใช่จากลิงก์ที่มีคนส่งมาในแชท

ระวังกลุ่ม ลิงก์ และโอเพนแชท

ต่อให้ตั้งค่าครบ มิจฉาชีพก็ยังเข้าถึงเราได้ผ่านการเชิญเข้ากลุ่ม สมาชิกในกลุ่มที่ไม่ได้เป็นเพื่อนกับเรายังเห็นชื่อและรูปโปรไฟล์ และอาจทักแชทส่วนตัวมาได้ ข้อปฏิบัติที่ควรทำ

  • ไม่ตอบรับคำเชิญกลุ่มจากคนที่ไม่รู้จัก โดยเฉพาะกลุ่มชื่อชวนลงทุน หาเงินออนไลน์ แจกของ หรือรับงานกดไลก์ (อ่านหลอกให้ทำงานกดไลก์ได้เงิน) และหลอกลงทุนออนไลน์
  • ระวังกลุ่มที่มีคนพูดเรื่องได้กำไรพร้อมกันหลายคน สมาชิกที่โพสต์โชว์สลิปอาจเป็นบัญชีหน้าม้าของคนตั้งกลุ่มเอง
  • ไม่กดลิงก์ที่ให้ล็อกอิน LINE ถ้าลิงก์พาไปหน้าที่ขอให้กรอกอีเมล รหัสผ่าน หรือรหัสยืนยัน ให้ปิดทิ้ง การเข้าสู่ระบบควรทำในแอปเท่านั้น
  • ในโอเพนแชท ใช้ชื่อและรูปที่ไม่ระบุตัวตน อย่าบอกเบอร์ ที่อยู่ หรือที่ทำงาน คนที่ทักส่วนตัวมาชวนคุยต่อนอกกลุ่ม หรือชวนย้ายไปแอปอื่น ควรระวัง
  • ออกจากกลุ่มที่ไม่ได้ใช้ ยิ่งอยู่หลายกลุ่ม ยิ่งมีคนแปลกหน้าเห็นโปรไฟล์ของเรามาก

เมื่อคนแปลกหน้าแอดหรือทักมา: ทำอะไรดี

ใช้ลำดับการตัดสินใจง่ายๆ นี้ทุกครั้งที่มีบัญชีที่ไม่รู้จักทักมา

  1. ไม่ตอบทันที ดูชื่อ รูป และสิ่งที่เขาพูด ถ้าเป็นข้อความทั่วไปแบบ "สวัสดีค่ะ ใช่คุณ...ไหม" หรือ "ส่งผิดคนขอโทษค่ะ" มักเป็นการเปิดบทสนทนาเพื่อชวนคุยต่อ ไม่ต้องตอบ
  2. ถ้าอ้างเป็นคนรู้จัก เช่น บอกว่าเป็นญาติที่เปลี่ยนบัญชีใหม่ ให้โทรหาเจ้าตัวผ่านเบอร์ที่เราบันทึกไว้เองก่อน อย่าใช้เบอร์ที่อีกฝ่ายส่งมา
  3. ถ้าอ้างเป็นหน่วยงาน ธนาคาร หรือตำรวจ ให้รู้ไว้ว่าหน่วยงานจริงไม่ทำคดีหรือขอโอนเงินผ่านแชทส่วนตัว ไม่ต้องตอบ แล้วติดต่อหน่วยงานนั้นผ่านช่องทางทางการ (ดูแอบอ้างเป็นตำรวจหรือ DSI)
  4. บล็อก เปิดแชทนั้นแล้วเลือกบล็อก หรือจัดการจากส่วนคำขอแชท บัญชีที่ถูกบล็อกจะส่งข้อความหาเราไม่ได้
  5. รายงาน ถ้าข้อความเข้าข่ายหลอกลวง ให้ใช้เมนูรายงานในแชทนั้นเพื่อแจ้งไปยัง LINE ช่วยให้บัญชีนั้นถูกตรวจสอบ และถ้ามีเบอร์โทรที่เกี่ยวข้อง สามารถรายงานเบอร์บน SpamInThaiหรือเช็คเบอร์ว่ามีคนรายงานไว้หรือยัง
  6. ถ้าโอนเงินไปแล้ว ติดต่อธนาคารผ่านเบอร์ทางการทันที โทรสายด่วน AOC 1441 และดูเช็กลิสต์โดนหลอกโอนเงิน

ตั้งค่า LINE ให้พ่อแม่และผู้สูงอายุ

ผู้สูงอายุหลายคนใช้ LINE คุยกับลูกหลานเป็นหลัก และไม่ค่อยเข้าไปดูหน้าตั้งค่า ช่วงที่ไปเยี่ยมบ้านเป็นโอกาสดีที่จะนั่งตั้งค่าให้พร้อมกัน แนะนำให้ทำตามลำดับนี้

  1. อัปเดตแอป LINE ให้เป็นเวอร์ชันล่าสุด เพื่อให้มีฟีเจอร์คัดกรองข้อความจากคนที่ไม่ใช่เพื่อน
  2. ปิดอนุญาตให้เพิ่มเป็นเพื่อน และปิดเพิ่มเพื่อนด้วย ID ตามขั้นที่ 1 และ 2
  3. ลบหรือบล็อกบัญชีแปลกหน้า ไล่ดูรายชื่อเพื่อนกับท่าน ถามว่ารู้จักคนไหนบ้าง บัญชีที่ท่านจำไม่ได้และไม่เคยคุยจริง ให้ซ่อนหรือบล็อก
  4. ออกจากกลุ่มที่ไม่รู้จัก โดยเฉพาะกลุ่มขายของ แจกรางวัล หรือชวนลงทุน
  5. ลงทะเบียนอีเมลและรหัสผ่าน ใช้อีเมลที่ลูกหลานช่วยดูแลได้ จดรหัสผ่านไว้ในที่ปลอดภัยที่ท่านรู้
  6. ปักหมุดแชทครอบครัว เพื่อให้ท่านแยกออกง่ายว่าใครคือคนในบ้านจริง
  7. ตกลง "คำลับ" ของครอบครัว ถ้ามีใครอ้างเป็นลูกหลานแล้วขอเงิน ให้ถามคำนี้ หรือโทรกลับเบอร์เดิมทุกครั้ง

ประโยคสั้นๆ ที่ใช้คุยกับพ่อแม่: "ถ้ามีใครทักไลน์มาที่แม่ไม่รู้จัก ไม่ต้องตอบนะ ถ้าเขาบอกว่าเป็นตำรวจ ธนาคาร หรือเป็นหนู แล้วพูดเรื่องเงิน ให้วางมือถือไว้ก่อน แล้วโทรหาหนูที่เบอร์เดิม ไม่มีใครดีๆ เร่งให้โอนเงินในแชทหรอก" อ่านวิธีคุยกับผู้ใหญ่ในบ้านเพิ่มเติมได้ที่คู่มือกันพ่อแม่โดนหลอก

สำหรับสายโทรเข้าจากเบอร์แปลก ซึ่งมักเป็นทางเข้าแรกก่อนจะชวนแอดไลน์ ให้ตั้งค่าปิดเสียงสายไม่รู้จักในโทรศัพท์ (ดูวิธีตั้งค่า Android และ iPhone) หรือติดตั้งแอป SpamInThaiที่ขึ้นเตือนเมื่อเบอร์ที่โทรเข้ามีคนรายงาน

เช็คลิสต์ตั้งค่า LINE กันมิจฉาชีพ (ทำครั้งเดียว ทบทวนทุก 3-6 เดือน)

  • ☐ ตั้งค่า > เพื่อน: ปิด อนุญาตให้เพิ่มเป็นเพื่อน
  • ☐ ตั้งค่า > เพื่อน: ปิด เพิ่มเพื่อนอัตโนมัติ ถ้าไม่ต้องการให้ดึงสมุดโทรศัพท์
  • ☐ ตั้งค่า > โปรไฟล์: ปิด อนุญาตให้เพิ่มเพื่อนด้วย ID
  • ☐ แชท > เครื่องหมายบวก > คิวอาร์โค้ดของฉัน: กด โหลดใหม่ ถ้าเคยแชร์คิวอาร์โค้ดไว้ในที่สาธารณะ
  • ☐ เปิดดูส่วนคำขอแชทจากคนที่ไม่ใช่เพื่อน แล้วลบหรือบล็อกบัญชีที่ไม่รู้จัก
  • ☐ ตั้งค่า > ความเป็นส่วนตัว: เปิด ล็อครหัสผ่าน (สำรองแชทก่อน และจำรหัสให้ได้)
  • ☐ ตั้งค่า > บัญชี: ลงทะเบียน รหัสผ่าน และ อีเมล
  • ☐ ตั้งค่า > บัญชี: ตรวจรายการอุปกรณ์ที่เข้าสู่ระบบ ออกจากระบบเครื่องที่ไม่รู้จัก
  • ☐ ออกจากกลุ่มที่ไม่รู้จักหรือไม่ได้ใช้
  • ☐ ตกลงกับคนในครอบครัวว่า เรื่องเงินต้องยืนยันทางโทรศัพท์ทุกครั้ง

ข้อมูลในบทความนี้เป็นข้อมูลทั่วไปเพื่อการป้องกัน ไม่ใช่คำแนะนำทางกฎหมาย ชื่อเมนูและขั้นตอนอาจเปลี่ยนตามการอัปเดตของแอป ให้ยึดหน้าช่วยเหลือทางการของ LINE เป็นหลัก ถ้าเกิดความเสียหายทางการเงินแล้ว ให้ติดต่อธนาคารและเจ้าหน้าที่ตำรวจโดยเร็ว ดูช่องทางแจ้งเหตุได้ที่สายด่วน 1441 1155 1212 อ่านวิธีที่เราตรวจสอบข้อมูลได้ที่นโยบายการตรวจสอบข้อมูล

ปิด "อนุญาตให้เพิ่มเป็นเพื่อน" แล้ว เพื่อนจริงจะยังเพิ่มเราได้ไหม

ได้ แต่ต้องใช้วิธีอื่น เช่น ให้เขาสแกนคิวอาร์โค้ดของเราต่อหน้า หรือเราเป็นฝ่ายเพิ่มเขาเอง การตั้งค่านี้ปิดเฉพาะการค้นหาด้วยเบอร์โทรศัพท์ ไม่ได้ลบเพื่อนที่มีอยู่แล้ว และไม่ได้ทำให้คนที่เป็นเพื่อนกันอยู่แล้วส่งข้อความหาเราไม่ได้

ปิด "เพิ่มเพื่อนอัตโนมัติ" ต่างจากปิด "อนุญาตให้เพิ่มเป็นเพื่อน" อย่างไร

เพิ่มเพื่อนอัตโนมัติคือการที่ LINE ดึงเบอร์ในสมุดโทรศัพท์ของเรามาเพิ่มเป็นเพื่อนให้ ส่วนอนุญาตให้เพิ่มเป็นเพื่อนคือการยอมให้คนที่มีเบอร์เราค้นหาเราเจอ ถ้าเป้าหมายคือกันคนแปลกหน้าที่ได้เบอร์เราไป ตัวที่สำคัญกว่าคืออนุญาตให้เพิ่มเป็นเพื่อน แต่ปิดทั้งสองอย่างได้ถ้าไม่ได้ใช้

มีคนแปลกหน้าทักมาใน LINE ทั้งที่เราปิดการเพิ่มเพื่อนแล้ว เป็นไปได้อย่างไร

เป็นไปได้หลายทาง เช่น เขาได้คิวอาร์โค้ดหรือลิงก์เพิ่มเพื่อนของเราที่เคยแชร์ไว้ อยู่ในกลุ่มเดียวกันกับเรา หรือเราเคยเปิดการตั้งค่าไว้ก่อนหน้านี้ ให้โหลดคิวอาร์โค้ดใหม่เพื่อให้ลิงก์เดิมใช้ไม่ได้ ออกจากกลุ่มที่ไม่รู้จัก แล้วบล็อกบัญชีนั้น

ถ้าลืมรหัสที่ตั้งไว้ในล็อครหัสผ่านของ LINE จะเกิดอะไรขึ้น

ตามหน้าช่วยเหลือของ LINE ถ้าลืมรหัสนี้ต้องลบแอปแล้วติดตั้งใหม่ ประวัติแชทที่ยังไม่ได้สำรองไว้จะหายไป จึงควรสำรองประวัติแชทก่อน และจดรหัสไว้ในที่ปลอดภัยโดยเฉพาะในเครื่องของผู้สูงอายุ

บัญชีที่มีโล่สีเขียวหรือน้ำเงิน แปลว่าปลอดภัย 100% ไหม

โล่บอกว่าบัญชีผ่านการรับรองจาก LINE แต่ไม่ได้แปลว่าทุกข้อความที่อ้างชื่อองค์กรนั้นเป็นของจริง ให้ดูชื่อบัญชีและโล่ให้ละเอียด และถ้ามีคนทักมาขอให้โอนเงินหรือกรอกรหัส ให้ติดต่อองค์กรนั้นผ่านเบอร์หรือเว็บไซต์ทางการที่หาเองก่อนเสมอ
