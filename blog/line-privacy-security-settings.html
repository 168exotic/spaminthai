ตั้งค่า LINE ให้ปลอดภัยจากมิจฉาชีพ: ปิดการเพิ่มเพื่อน ปฏิเสธข้อความคนแปลกหน้า เช็คอุปกรณ์ที่ล็อกอิน และเช็กลิสต์ 10 นาทีสำหรับพ่อแม่

คำตอบสั้น: การตั้งค่า LINE ให้ปลอดภัยจากมิจฉาชีพมีหัวใจอยู่สามเรื่อง คือ ไม่ให้คนแปลกหน้าเข้ามาถึงเราง่ายๆ (ปิดการให้คนอื่นเพิ่มเพื่อนด้วยเบอร์โทรและ ID และเปิดปฏิเสธการรับข้อความจากคนที่ไม่ใช่เพื่อน) ไม่ให้ใครแอบใช้บัญชีเราจากเครื่องอื่น (ตรวจอุปกรณ์ที่ล็อกอิน ผูกอีเมล และไม่บอกรหัสยืนยันกับใคร) และ ดูให้ออกว่าใครเป็นบัญชีจริง (บัญชีทางการกับบัญชีปลอมชื่อคล้าย) ทั้งหมดทำได้ในเมนูตั้งค่าของแอป ใช้เวลาประมาณ 10 นาที และท้ายบทความมีเช็กลิสต์สำหรับนั่งทำกับพ่อแม่

บทความนี้เน้นการตั้งค่าและการรับมือเมื่อคนแปลกหน้าทักมา ถ้าคุณกำลังเจอเพื่อนทักมายืมเงินแล้วสงสัยว่าบัญชีเพื่อนโดนแฮก ให้อ่านวิธีเช็คก่อนโอนเมื่อเพื่อนทักมายืมเงิน ส่วนการตั้งรหัสผ่านที่แข็งแรงและเปิดยืนยันตัวตนสองชั้นแบบละเอียด อยู่ในบทความตั้งรหัสผ่านและเปิด 2FA

หมายเหตุเรื่องชื่อเมนู: LINE ปรับหน้าตาแอปบ่อย ชื่อเมนูและตำแหน่งอาจต่างกันเล็กน้อยระหว่าง Android กับ iPhone และระหว่างเวอร์ชัน ถ้าหาไม่เจอ ให้เข้า หน้าหลัก > ไอคอนฟันเฟือง (ตั้งค่า) แล้วใช้ช่องค้นหาด้านบนของหน้าตั้งค่า พิมพ์คำสำคัญ เช่น “เพื่อน” “ข้อความ” หรือ “อุปกรณ์” และอัปเดตแอปเป็นเวอร์ชันล่าสุดก่อนเริ่ม

ทำไมมิจฉาชีพชอบใช้ LINE

LINE เป็นแอปที่คนไทยแทบทุกบ้านใช้ ทั้งคุยกับลูกหลาน รับข่าวจากร้านค้า และติดต่อหน่วยงาน ความคุ้นเคยนี้เองที่มิจฉาชีพใช้เป็นช่องทาง เพราะคนส่วนใหญ่ไม่ได้ระวังข้อความใน LINE เท่ากับ SMS หรือสายโทรเข้าจากเบอร์แปลก

เส้นทางที่พบบ่อยมีลักษณะคล้ายกัน คือเริ่มจากช่องทางอื่นก่อน เช่น โทรศัพท์ SMS หรือโฆษณาในโซเชียล แล้ว ชวนให้ย้ายมาคุยต่อใน LINE เพราะใน LINE ส่งรูปเอกสารปลอม ส่งลิงก์ ส่งไฟล์ และวิดีโอคอลได้สะดวก บางกรณีไม่ต้องชวนด้วยซ้ำ แค่รู้เบอร์โทรของเรา ถ้าเราเปิดให้คนอื่นเพิ่มเพื่อนด้วยเบอร์โทรไว้ ก็หาเราเจอและทักมาได้ทันที

รูปแบบที่ผู้ใช้เล่าให้เราฟังบ่อยๆ ได้แก่

  • คนแปลกหน้าทักมาแบบเป็นกันเอง “สวัสดีค่ะ ใช่คุณ...ไหมคะ” หรือ “ขอโทษค่ะ ทักผิดคน” แล้วชวนคุยต่อจนสนิท ก่อนเปลี่ยนเรื่องไปที่การลงทุนหรืองานเสริม
  • บัญชีที่ตั้งชื่อและรูปให้เหมือนหน่วยงาน ธนาคาร ขนส่ง หรือหน่วยงานรัฐ ทักมาบอกว่ามีปัญหาต้องแก้ไขด่วน แล้วส่งลิงก์ให้กด
  • ถูกดึงเข้ากลุ่มหรือ OpenChat ที่มีคนหลายสิบคนคุยกันคึกคัก โพสต์สลิปกำไรหรือรายได้จากงานกดไลก์ ทั้งที่คนส่วนใหญ่ในกลุ่มอาจเป็นบัญชีที่ทีมเดียวกันสร้างขึ้น
  • ขอรหัสยืนยัน 6 หลัก โดยอ้างว่า “ส่งผิดเบอร์” หรือ “ช่วยยืนยันตัวตนให้หน่อย” ซึ่งจริงๆ คือรหัสที่ใช้ล็อกอินบัญชีของเราจากเครื่องอื่น

การตั้งค่าที่ดีไม่ได้กันการหลอกได้ทุกแบบ แต่ช่วยลดจำนวนคนแปลกหน้าที่เข้าถึงเราได้มาก และทำให้ข้อความแปลกๆ ถูกแยกออกจากแชทปกติ ซึ่งสำคัญมากสำหรับผู้สูงอายุที่อ่านทุกข้อความที่เข้ามา

ขั้นที่ 1: ปิดประตูหน้าบ้าน ไม่ให้คนแปลกหน้าเพิ่มเพื่อนเราได้เอง

LINE มีการตั้งค่าที่เกี่ยวกับการเพิ่มเพื่อนอยู่หลายจุด แต่ละจุดทำงานต่างกัน ควรเข้าใจก่อนว่าปิดแล้วได้อะไร

ในเมนูตั้งค่า > เพื่อน

  • อนุญาตให้ผู้อื่นเพิ่มเป็นเพื่อน ถ้าเปิดไว้ คนที่มีเบอร์โทรของเราอยู่ในสมุดรายชื่อ และเปิดการเพิ่มเพื่อนอัตโนมัติไว้ จะเห็นเราและเพิ่มเราได้ทันที ปัญหาคือเบอร์ของเราอาจอยู่ในรายชื่อของคนที่เราไม่รู้จัก เช่น ร้านค้าที่เคยซื้อของ หรือรายชื่อที่หลุดออกไป แนะนำให้ปิด
  • เพิ่มเพื่อนอัตโนมัติ ตัวนี้ทำงานกลับกัน คือ LINE จะดึงคนในสมุดรายชื่อของเรามาเป็นเพื่อนให้เอง ข้อเสียคือรายชื่อเพื่อนจะรกไปด้วยเบอร์ที่เราเคยบันทึกไว้นานแล้ว รวมถึงเบอร์ที่ถูกเปลี่ยนเจ้าของไปแล้ว ถ้าปิดไว้ เราจะเพิ่มเฉพาะคนที่ตั้งใจเพิ่ม

การเพิ่มเพื่อนด้วย ID

ถ้าคุณเคยตั้ง LINE ID ไว้ จะมีตัวเลือก อนุญาตให้เพิ่มเพื่อนด้วย ID ในบางเวอร์ชันอยู่ในเมนูตั้งค่า > โปรไฟล์ บางเวอร์ชันอยู่ในส่วนความเป็นส่วนตัว ถ้าเปิดไว้ ใครก็ตามที่รู้หรือเดา ID ของเราได้ก็ค้นหาและทักมาได้ ID ที่เดาง่าย เช่น ชื่อจริงต่อด้วยปีเกิด เสี่ยงเป็นพิเศษ

คนทั่วไปที่ไม่ได้ใช้ LINE ติดต่อลูกค้า ปิดไว้ได้เลย ถ้าวันหนึ่งต้องการให้ใครเพิ่มเพื่อน ให้ใช้วิธีที่ปลอดภัยกว่า คือให้เขาสแกนคิวอาร์โค้ดของเราต่อหน้า หรือเราเป็นฝ่ายเพิ่มเขาเอง

เคล็ดลับเรื่องคิวอาร์โค้ด: คิวอาร์โค้ดของเราใน LINE ใช้เพิ่มเพื่อนได้ทันที อย่าโพสต์ลงโซเชียลหรือส่งต่อในกลุ่มสาธารณะ ถ้าเคยส่งออกไปแล้ว ในหน้าคิวอาร์โค้ดของฉันมีปุ่มโหลดใหม่ เพื่อเปลี่ยนเป็นโค้ดใหม่ให้โค้ดเดิมใช้ไม่ได้

ขั้นที่ 2: ปฏิเสธการรับข้อความจากคนที่ไม่ใช่เพื่อน

แม้จะปิดการเพิ่มเพื่อนแล้ว คนแปลกหน้ายังมีทางส่งข้อความหาเราได้ เช่น เจอเราในกลุ่มเดียวกัน หรือได้ข้อมูลบัญชีเราจากทางอื่น การตั้งค่าที่ช่วยตรงนี้คือ ปฏิเสธการรับข้อความ ซึ่งอยู่ในส่วน ตั้งค่า > ความเป็นส่วนตัว เมื่อเปิดไว้ ข้อความใหม่จากบัญชีที่ไม่ได้อยู่ในรายชื่อเพื่อนของเราจะไม่เข้ามา

นอกจากนี้ LINE ประเทศไทยได้เพิ่มกล่อง คำขอจากผู้ที่ไม่ใช่เพื่อน ซึ่งรวบรวมข้อความและคำเชิญจากคนที่ไม่ได้เป็นเพื่อนแยกไว้ ไม่ปนกับแชทหลัก เปิดเข้าไปดูแล้วเลือกได้ว่าจะรับ บล็อก หรือรายงาน วิธีคิดง่ายๆ คือ

  • ข้อความในกล่องนี้ไม่ใช่เพื่อนของเรา ไม่ว่าจะใช้ชื่อหรือรูปอะไร ให้อ่านด้วยความระวังเสมอ
  • ถ้าอ้างเป็นคนรู้จัก เช่น “นี่ลูกพี่ลูกน้องเอง เปลี่ยนไลน์ใหม่” ให้โทรหาคนนั้นที่เบอร์เดิมที่เรามีอยู่ก่อนจะตอบ
  • ถ้าอ้างเป็นหน่วยงานหรือบริษัท หน่วยงานจริงแทบไม่เคยทักหาประชาชนแบบส่วนตัวผ่านบัญชีที่ยังไม่ได้เป็นเพื่อน

สำหรับผู้สูงอายุที่คุยกับคนเดิมๆ เป็นหลัก การเปิดปฏิเสธการรับข้อความไว้ตลอดเวลาแทบไม่มีข้อเสีย สำหรับคนทำงานที่ต้องคุยกับลูกค้าใหม่บ่อย อาจเปิดไว้ไม่ได้ ก็ให้ใช้กล่องคำขอเป็นด่านกรองแทน และยึดหลักว่าข้อความจากคนที่ไม่ใช่เพื่อนต้องไม่นำไปสู่การกดลิงก์ ติดตั้งแอป หรือโอนเงิน

ขั้นที่ 3: Letter Sealing และการตั้งค่าแชทที่ไม่ควรไปแตะ

Letter Sealing คือการเข้ารหัสแบบต้นทางถึงปลายทางของ LINE ครอบคลุมข้อความ การโทร และการแชร์ตำแหน่ง LINE ประเทศไทยชี้แจงว่าข้อมูลเข้าถึงได้เฉพาะผู้ส่งและผู้รับ และใช้กับทุกแชทโดยอัตโนมัติเมื่อใช้แอปเวอร์ชันล่าสุด

สิ่งที่ควรรู้คือ

  • ไม่ต้องไปปิด เคยมีคลิปที่แชร์กันว่าให้ปิด Letter Sealing เพื่อความปลอดภัย ซึ่งเป็นความเข้าใจผิด การปิดทำให้การเข้ารหัสอ่อนลง ไม่ได้ทำให้ปลอดภัยขึ้น
  • Letter Sealing กันคนดักฟังระหว่างทาง ไม่ได้กันคนที่เราคุยด้วย ถ้าคนที่เราคุยด้วยคือมิจฉาชีพ การเข้ารหัสไม่ได้ช่วยอะไร เพราะเขาคือปลายทางที่อ่านข้อความได้ตามปกติ
  • อัปเดตแอปให้ใหม่เสมอ ทั้งเพื่อให้การเข้ารหัสทำงานครบ และเพื่อให้ได้ฟีเจอร์ป้องกันใหม่ๆ

ในส่วนการตั้งค่าแชท LINE ยังเพิ่มฟีเจอร์ ตรวจจับเว็บไซต์ฟิชชิ่ง ที่เทียบลิงก์ในแชทกับฐานข้อมูลเว็บที่เคยถูกรายงานว่าหลอกลวง และขึ้นคำเตือนก่อนเปิด ควรเข้าไปดูในเมนูตั้งค่าแชทว่าเปิดไว้แล้ว นอกจากนี้ตั้งแต่เดือนพฤษภาคม 2569 LINE ประเทศไทยเริ่มแสดง ป๊อปอัปเตือนเมื่อมีสายโทรหรือวิดีโอคอลจากบัญชีที่มีความเสี่ยง เช่น บัญชีที่ไม่ใช่เพื่อน หรือบัญชีที่เพิ่งสร้างใหม่ ถ้าเห็นป๊อปอัปนี้ ให้ถือเป็นสัญญาณให้หยุดคิดก่อนรับสาย

ทั้งสองฟีเจอร์เป็นด่านเสริม ไม่ได้แปลว่าลิงก์ที่ไม่มีคำเตือนจะปลอดภัย เว็บปลอมที่เพิ่งสร้างอาจยังไม่อยู่ในฐานข้อมูล

ขั้นที่ 4: ใครล็อกอิน LINE ของเราอยู่บ้าง

บัญชี LINE หนึ่งบัญชีใช้บนมือถือหลักได้หนึ่งเครื่อง แต่ล็อกอินเพิ่มบนคอมพิวเตอร์ แท็บเล็ต หรือเว็บได้ ช่องทางนี้เองที่มิจฉาชีพใช้ เมื่อได้รหัสผ่านหรือรหัสยืนยันไป เขาจะล็อกอินจากคอมพิวเตอร์ของเขา อ่านแชทของเรา และส่งข้อความหาเพื่อนเราได้โดยที่มือถือเรายังใช้งานปกติ

สิ่งที่ควรตรวจ

  1. ดูรายการอุปกรณ์ที่ล็อกอินอยู่ ในเมนูตั้งค่า > บัญชี จะมีรายการอุปกรณ์ที่ล็อกอินบัญชีของเราอยู่ ถ้าเจอคอมพิวเตอร์หรือแท็บเล็ตที่ไม่ใช่ของเรา ให้กดออกจากระบบอุปกรณ์นั้นทันที แล้วเปลี่ยนรหัสผ่าน
  2. ปิดการอนุญาตให้ล็อกอินจากอุปกรณ์อื่น ถ้าไม่ได้ใช้ ในหน้าบัญชีมีตัวเลือกอนุญาตให้ล็อกอิน ถ้าคุณหรือพ่อแม่ใช้ LINE แค่บนมือถือ การปิดตัวนี้ทำให้ไม่มีใครล็อกอินบัญชีบนคอมพิวเตอร์หรือแท็บเล็ตได้ แม้จะได้รหัสผ่านไป ข้อเสียคือถ้าวันหนึ่งต้องใช้ LINE บนคอมพิวเตอร์ ต้องกลับมาเปิดก่อน
  3. อ่านข้อความแจ้งเตือนการล็อกอิน เมื่อมีการล็อกอินจากคอมพิวเตอร์หรือเว็บ LINE จะส่งข้อความแจ้งในแชท ถ้าเห็นการแจ้งเตือนที่เราไม่ได้ทำเอง อย่าปล่อยผ่าน
  4. ออกจากระบบทุกครั้งที่ใช้เครื่องคนอื่น ถ้าเคยล็อกอิน LINE บนคอมพิวเตอร์ที่ทำงาน ร้านอินเทอร์เน็ต หรือเครื่องของญาติ ให้ออกจากระบบเมื่อใช้เสร็จ หรือออกจากระบบอุปกรณ์นั้นจากหน้ารายการอุปกรณ์ในมือถือ

อีเมลและรหัสผ่านผูกบัญชี

ในเมนูตั้งค่า > บัญชี ให้ตรวจสองอย่าง คือ มีอีเมลผูกไว้หรือยัง และเป็นอีเมลที่เรายังเข้าได้จริงไหม อีเมลที่ผูกไว้ใช้กู้บัญชีเมื่อเปลี่ยนเครื่องหรือมีปัญหา ถ้าเป็นอีเมลเก่าที่ลืมรหัสไปแล้ว ก็เท่ากับไม่มี อีกอย่างคือรหัสผ่าน LINE ไม่ควรซ้ำกับรหัสของบริการอื่น ในหน้าบัญชีเดียวกันยังมีตัวเลือก การตรวจสอบยืนยัน 2 ระดับ ซึ่งเพิ่มการยืนยันในแอปเมื่อมีการใช้บัญชี LINE ล็อกอินเข้าเว็บหรือบริการอื่น ควรเปิดไว้ รายละเอียดการตั้งรหัสผ่านอยู่ในบทความเรื่องรหัสผ่านและ 2FA

สัญญาณว่ามีคนอื่นใช้บัญชีเราอยู่: เพื่อนบอกว่าได้ข้อความแปลกๆ จากเรา, มีแชทที่เราไม่ได้พิมพ์ หรือข้อความถูกอ่านแล้วทั้งที่เรายังไม่ได้เปิด, มีการแจ้งเตือนล็อกอินจากคอมพิวเตอร์ที่เราไม่ได้ใช้, รายการอุปกรณ์มีเครื่องที่ไม่รู้จัก ถ้าเจอข้อใดข้อหนึ่ง ให้ออกจากระบบอุปกรณ์นั้น เปลี่ยนรหัสผ่าน และแจ้งเพื่อนในรายชื่อทันที

ขั้นที่ 5: รหัสยืนยัน 6 หลัก คือกุญแจบ้าน ห้ามบอกใคร

เมื่อมีการล็อกอิน LINE บนเครื่องใหม่หรือบนคอมพิวเตอร์ ระบบจะให้ยืนยันด้วยรหัสตัวเลข รหัสนี้มีไว้ยืนยันว่า เจ้าของบัญชีเป็นคนล็อกอินเอง ใครได้รหัสไปพร้อมจังหวะที่ถูกต้อง ก็เข้าบัญชีเราได้

มุกที่ใช้ขอรหัสมักฟังดูไม่มีพิษภัย เช่น

  • “ขอโทษค่ะ เมื่อกี้ส่งรหัสไปที่เบอร์คุณผิด ช่วยบอกตัวเลขหน่อยได้ไหม”
  • “ร่วมกิจกรรมโหวตให้หลานหน่อย ระบบจะส่งรหัสไป แคปหน้าจอส่งกลับมานะ”
  • “เจ้าหน้าที่ LINE แจ้งว่าบัญชีของคุณจะถูกระงับ กรุณายืนยันตัวตนด้วยรหัสที่ได้รับ”

หลักจำง่ายๆ สำหรับทุกคนในบ้าน: รหัสที่เด้งขึ้นมาในมือถือเรา ใช้ได้กับมือเราคนเดียว ไม่มีเหตุผลที่คนอื่น เพื่อน หรือเจ้าหน้าที่จะต้องขอ ถ้าได้รหัสทั้งที่ไม่ได้กำลังล็อกอินอะไร แปลว่ามีคนพยายามเข้าบัญชีเรา ให้เพิกเฉยต่อข้อความนั้น แล้วไปตรวจอุปกรณ์ที่ล็อกอินและเปลี่ยนรหัสผ่าน

ข้อนี้ใช้กับรหัส OTP ของธนาคารและบริการอื่นด้วยเช่นกัน ถ้าอยากอ่านเรื่องการขโมยรหัสผ่านซิม ดูมิจฉาชีพยึดซิมเพื่อรับ OTP

ขั้นที่ 6: กลุ่มและ OpenChat ที่ถูกดึงเข้าไป

กลุ่มเป็นเครื่องมือที่มิจฉาชีพชอบใช้ เพราะความคึกคักในกลุ่มทำให้ดูน่าเชื่อ เมื่อเห็นหลายสิบคนโพสต์ว่าได้กำไร ได้ค่าคอมมิชชัน หรือขอบคุณ “อาจารย์” คนทั่วไปจะเริ่มคิดว่าคงไม่ได้หลอกกันทั้งกลุ่ม ความจริงคือหลายกลุ่มมีสมาชิกส่วนใหญ่เป็นหน้าม้า

สัญญาณว่ากลุ่มนี้น่าสงสัย

  • ถูกดึงเข้ากลุ่มโดยไม่มีใครถามก่อน และไม่รู้จักใครในกลุ่มเลย
  • ทุกคนในกลุ่มพูดไปทางเดียวกัน โพสต์สลิปหรือภาพหน้าจอกำไรถี่ๆ ไม่มีใครถามหรือแย้งเลย
  • มีแอดมินที่เรียกตัวเองว่าโค้ช อาจารย์ หรือผู้ช่วย แล้วทักส่วนตัวมาหลังเราเข้ากลุ่มไม่นาน
  • ชวนให้ทำ “ภารกิจ” ง่ายๆ ได้เงินจริงครั้งแรก แล้วค่อยให้โอนเงินเพื่อทำภารกิจที่ใหญ่ขึ้น (รายละเอียดในมุกงานกดไลก์ได้เงิน)
  • ให้ดาวน์โหลดแอปลงทุนหรือแอปเทรดจากลิงก์ ไม่ใช่จาก Store (อ่านเพิ่มที่หลอกลงทุนออนไลน์)

ทำอย่างไรเมื่อถูกดึงเข้ากลุ่ม

  1. ไม่กดลิงก์ ไม่ดาวน์โหลดไฟล์ ไม่สแกนคิวอาร์ที่โพสต์ในกลุ่ม
  2. ออกจากกลุ่ม และรายงานกลุ่มผ่านเมนูในห้องแชท
  3. ถ้ามีคนในกลุ่มทักส่วนตัวตามมา ให้บล็อกและรายงานบัญชีนั้น
  4. ถ้าเปิดปฏิเสธการรับข้อความไว้ คำเชิญเข้ากลุ่มจากคนที่ไม่ใช่เพื่อนมักไปอยู่ในกล่องคำขอ ให้ปฏิเสธจากตรงนั้นได้เลย

OpenChat เป็นห้องที่ใครก็เข้าได้ด้วยชื่อเล่นที่ตั้งใหม่ ไม่ต้องเห็นบัญชีหลักกัน ข้อดีคือความเป็นส่วนตัว ข้อเสียคือเราไม่มีทางรู้เลยว่าคนในห้องเป็นใคร อย่าย้ายบทสนทนาจาก OpenChat ไปคุยส่วนตัวกับคนที่เพิ่งรู้จัก และอย่าบอกเบอร์โทรหรือ ID ของบัญชีหลักในห้องที่เปิดสาธารณะ

ขั้นที่ 7: บัญชีทางการที่มีโล่ กับบัญชีปลอมชื่อคล้าย

ร้านค้า ธนาคาร และหน่วยงานส่วนใหญ่ใช้ LINE Official Account ในการสื่อสาร บัญชีที่ผ่านการตรวจสอบจาก LINE จะมี เครื่องหมายโล่ อยู่หน้าชื่อบัญชี สีและรูปแบบของโล่อาจแตกต่างกันตามประเภทบัญชีและถูกปรับเปลี่ยนได้ตามนโยบายของ LINE เราจึงไม่แนะนำให้จำแค่สีของโล่ แต่ให้ดูหลายอย่างประกอบกัน

วิธีดูว่าเป็นบัญชีจริงหรือปลอม

  • เราได้บัญชีมาจากไหน นี่คือข้อสำคัญที่สุด บัญชีที่เราเพิ่มเองจากลิงก์หรือคิวอาร์โค้ดบนเว็บไซต์ทางการ แอปทางการ หรือป้ายในสาขา น่าเชื่อกว่าบัญชีที่ทักเข้ามาหาเราก่อน หรือบัญชีที่มีคนส่งลิงก์มาให้
  • ชื่อที่คล้ายแต่ไม่เหมือน บัญชีปลอมมักเติมคำว่า “ช่วยเหลือ” “แจ้งปัญหา” “Support” หรือสะกดต่างไปเพียงตัวเดียว ใช้โลโก้ที่ก๊อปมาให้เหมือน
  • ไม่มีโล่ก็ไม่ได้แปลว่าปลอม มีโล่ก็ไม่ได้แปลว่าทำอะไรก็ได้ ร้านเล็กๆ จำนวนมากไม่มีโล่และเป็นร้านจริง ขณะเดียวกันบัญชีที่มีโล่ก็ไม่ควรขอรหัสผ่าน รหัส OTP หรือให้ติดตั้งแอปจากลิงก์
  • ใครทักก่อน บัญชีทางการโดยทั่วไปส่งข้อความหาเราได้เมื่อเราเพิ่มเป็นเพื่อนแล้ว ถ้าบัญชีที่อ้างเป็นธนาคารหรือหน่วยงานโผล่มาในกล่องคำขอจากผู้ที่ไม่ใช่เพื่อน ให้สงสัยไว้ก่อน

ถ้าไม่แน่ใจ ให้ปิดแชทนั้น แล้วติดต่อหน่วยงานผ่านช่องทางที่เราหาเอง เช่น เบอร์หลังบัตร แอปธนาคาร หรือเว็บไซต์ทางการ อย่าใช้เบอร์หรือลิงก์ที่ได้รับในแชท ระวังการค้นหาเบอร์ติดต่อจาก Google ด้วย เพราะมีโฆษณาหรือเพจปลอมแทรกอยู่ (ดูเบอร์คอลเซ็นเตอร์ปลอมจากการค้นหา)

เมื่อคนแปลกหน้าทักมา: ทำอะไรได้บ้าง

ต่อให้ตั้งค่าดีแค่ไหน วันหนึ่งก็ยังอาจมีคนแปลกหน้าทักมาได้ ตารางตัดสินใจด้านล่างใช้กับทุกคนในบ้าน

  • ทักมาว่า “ทักผิดคน” หรือชวนคุยเล่น ไม่ต้องตอบ ไม่ต้องอธิบาย บล็อกได้เลย การตอบแม้แต่คำเดียวเป็นการบอกว่าบัญชีนี้มีคนใช้งานจริง
  • อ้างเป็นคนรู้จักที่ “เปลี่ยนไลน์ใหม่” โทรหาคนนั้นที่เบอร์เดิม ถามเรื่องที่มีแต่เรากับเขารู้ ถ้าติดต่อไม่ได้ อย่าทำอะไรตามที่ขอ
  • อ้างเป็นธนาคาร ขนส่ง หรือหน่วยงาน ไม่กดลิงก์ ไม่ส่งรูปบัตร ไม่บอกรหัส ติดต่อหน่วยงานเองผ่านช่องทางทางการ แล้วรายงานบัญชีนั้น
  • เสนองาน รายได้เสริม หรือการลงทุน ยิ่งดูดีเกินจริงยิ่งต้องปฏิเสธ บล็อกและรายงาน
  • วิดีโอคอลเข้ามาจากบัญชีที่ไม่รู้จัก ไม่ต้องรับ ถ้ารับไปแล้วและอีกฝ่ายอ้างเป็นตำรวจหรือเจ้าหน้าที่ ให้วางสาย หน่วยงานจริงไม่สอบสวนทางวิดีโอคอล (อ่านเพิ่มที่มุกวิดีโอคอลกักตัว)
  • ส่งไฟล์ .apk หรือลิงก์ให้ติดตั้งแอป อย่าเปิดเด็ดขาด ไฟล์แบบนี้อาจเป็นแอปที่ควบคุมมือถือจากระยะไกล (ดูแอปปลอมควบคุมเครื่อง)

วิธีบล็อกและรายงานใน LINE

ในห้องแชทของบัญชีที่น่าสงสัย ให้เปิดเมนูของห้องแชท หรือแตะชื่อ/รูปโปรไฟล์ของบัญชีนั้น จะมีตัวเลือก บล็อก และ รายงาน ถ้าข้อความอยู่ในกล่องคำขอจากผู้ที่ไม่ใช่เพื่อน ก็เลือกบล็อกหรือรายงานได้จากตรงนั้น

  • บล็อก ทำให้บัญชีนั้นส่งข้อความหรือโทรหาเราไม่ได้ อีกฝ่ายไม่ได้รับแจ้งว่าถูกบล็อก ถ้าบล็อกผิดคน ปลดบล็อกได้ในเมนูตั้งค่า > เพื่อน > บัญชีที่บล็อค
  • รายงาน ส่งข้อมูลให้ LINE ตรวจสอบบัญชีนั้น ช่วยให้บัญชีหลอกลวงถูกจัดการเร็วขึ้น และช่วยคนอื่นด้วย ควรรายงานก่อนแล้วค่อยบล็อก
  • ก่อนลบแชท ให้แคปหน้าจอเก็บไว้ ทั้งหน้าโปรไฟล์ ชื่อบัญชี ข้อความ และลิงก์ที่ส่งมา ถ้ามีความเสียหายเกิดขึ้น หลักฐานเหล่านี้จำเป็นสำหรับการแจ้งความ (ดูเช็กลิสต์เก็บหลักฐาน)

ถ้าคนแปลกหน้าเริ่มต้นจากการโทรเข้าแล้วชวนให้แอดไลน์ ให้นำเบอร์นั้นไปเช็คเบอร์และรายงานเบอร์บน SpamInThai ด้วย เพื่อเตือนคนที่อาจถูกโทรหาด้วยเบอร์เดียวกัน

ถ้าโอนเงินหรือให้ข้อมูลไปแล้ว ให้ติดต่อธนาคารผ่านช่องทางทางการทันที โทรสายด่วนศูนย์ต่อต้านการฉ้อโกงออนไลน์ (AOC) 1441 และทำตามเช็กลิสต์เมื่อโดนหลอกโอนเงิน ยิ่งแจ้งเร็ว โอกาสระงับเงินยิ่งสูง

ข้อมูลในบทความนี้เป็นข้อมูลทั่วไปเพื่อการป้องกันตัวเอง ไม่ใช่คำแนะนำทางกฎหมาย ขั้นตอนการแจ้งความหรือการติดตามเงินคืนให้ยึดตามคำแนะนำของธนาคารและเจ้าหน้าที่ตำรวจ

เช็กลิสต์ 10 นาที: นั่งตั้งค่า LINE กับพ่อแม่

วิธีที่ได้ผลที่สุดคือนั่งข้างๆ แล้วให้ท่านกดเอง เราคอยบอก เพราะท่านจะจำได้ว่าเมนูอยู่ตรงไหน และเข้าใจว่าทำไปเพื่ออะไร ก่อนเริ่มให้อัปเดต LINE เป็นเวอร์ชันล่าสุดจาก Play Store หรือ App Store

  1. นาทีที่ 1-2: ตั้งค่า > เพื่อน ปิดอนุญาตให้ผู้อื่นเพิ่มเป็นเพื่อน และพิจารณาปิดเพิ่มเพื่อนอัตโนมัติ
  2. นาทีที่ 3: การเพิ่มเพื่อนด้วย ID ถ้ามี ID ให้ปิดอนุญาตให้เพิ่มเพื่อนด้วย ID
  3. นาทีที่ 4: ตั้งค่า > ความเป็นส่วนตัว เปิดปฏิเสธการรับข้อความ แล้วชี้ให้ท่านดูว่ากล่องคำขอจากผู้ที่ไม่ใช่เพื่อนอยู่ตรงไหน
  4. นาทีที่ 5: ตั้งค่าแชท ตรวจว่าเปิดการตรวจจับเว็บไซต์ฟิชชิ่งไว้
  5. นาทีที่ 6-7: ตั้งค่า > บัญชี ดูรายการอุปกรณ์ที่ล็อกอิน ออกจากระบบเครื่องที่ไม่รู้จัก ถ้าท่านใช้แค่มือถือ ให้ปิดการอนุญาตให้ล็อกอินจากอุปกรณ์อื่น ตรวจว่าอีเมลที่ผูกไว้ยังใช้ได้ และเปิดการตรวจสอบยืนยัน 2 ระดับ
  6. นาทีที่ 8: ไล่ดูรายชื่อกลุ่ม ออกจากกลุ่มที่ท่านไม่รู้จักหรือไม่ได้ตั้งใจเข้า โดยเฉพาะกลุ่มลงทุน กลุ่มหาเงิน และกลุ่มแจกของ
  7. นาทีที่ 9: ซ้อมบล็อกและรายงาน ให้ท่านลองเปิดเมนูของห้องแชทหนึ่งห้องเพื่อดูว่าปุ่มบล็อกและรายงานอยู่ตรงไหน (ไม่ต้องกดจริง)
  8. นาทีที่ 10: ตกลงกติกาบ้าน ใช้ประโยคด้านล่างนี้

ประโยคที่ใช้คุยกับพ่อแม่

แทนที่จะบอกยาวๆ ให้เลือกประโยคสั้นที่จำง่าย แล้วพูดซ้ำทุกครั้งที่เจอกัน

  • “ใครทักไลน์มาแล้วไม่ใช่เพื่อน ไม่ต้องตอบ แคปส่งมาให้หนูดูก่อน”
  • “เลขที่เด้งมาในมือถือ ห้ามบอกใคร แม้แต่คนที่บอกว่าเป็นหนู ถ้าหนูขอ ให้โทรมาถามหนูที่เบอร์นี้ก่อน”
  • “ลูกหลานเปลี่ยนไลน์ใหม่ แล้วทักมายืมเงิน ให้โทรเข้าเบอร์เดิมก่อนทุกครั้ง”
  • “ใครดึงเข้ากลุ่มที่ไม่รู้จัก กดออกได้เลย ไม่เสียมารยาท”
  • “ตำรวจ ธนาคาร ไปรษณีย์ ไม่วิดีโอคอลมาหาเรา ถ้าโทรมา วางได้เลย แล้วโทรหาหนู”

ตั้งรหัสลับประจำครอบครัวไว้สักคำ สำหรับใช้ถามยืนยันเวลามีคนอ้างเป็นลูกหลานทางแชทหรือโทรศัพท์ จะช่วยได้มากในยุคที่เสียงและรูปปลอมได้ (ดูเสียงปลอมด้วย AI) ถ้าอยากตั้งค่ามือถือทั้งเครื่องให้ท่านต่อ เช่น ปิดการติดตั้งแอปนอก Store และกรองสายแปลก ดูเช็กลิสต์ตั้งค่ามือถือพ่อแม่ 30 นาที และคู่มือป้องกันมิจฉาชีพสำหรับผู้สูงอายุ สำหรับสายโทรเข้าจากเบอร์แปลก ติดตั้งแอป SpamInThaiให้ขึ้นเตือนเมื่อเบอร์ที่โทรเข้ามีคนรายงานไว้

ตรวจซ้ำทุกเดือน: 3 อย่างที่ใช้เวลาไม่ถึงนาที

การตั้งค่าครั้งเดียวไม่พอ เพราะแอปอัปเดตแล้วบางครั้งมีตัวเลือกใหม่ หรือมีคนในบ้านเผลอเปิดบางอย่างกลับ แนะนำให้ตรวจสามอย่างนี้เดือนละครั้ง

  • รายการอุปกรณ์ที่ล็อกอิน มีเครื่องเกินจากที่เราใช้หรือไม่
  • กล่องคำขอจากผู้ที่ไม่ใช่เพื่อน มีอะไรค้างอยู่บ้าง ถ้ามีบัญชีน่าสงสัย ให้รายงานแล้วลบ
  • รายชื่อกลุ่ม มีกลุ่มใหม่ที่ไม่รู้จักโผล่มาหรือไม่

ถ้าบ้านไหนมีเด็กหรือวัยรุ่นที่ใช้ LINE ด้วย การตั้งค่าแบบเดียวกันนี้ใช้ได้ และควรคุยเรื่องการไม่ส่งรูปส่วนตัวให้คนที่รู้จักทางออนไลน์ (อ่านเพิ่มที่ภัยออนไลน์สำหรับเด็กและวัยรุ่น)

คำถามที่พบบ่อย

ปิดการเพิ่มเพื่อนแล้ว เพื่อนจริงจะหาเราไม่เจอไหม

คนที่เป็นเพื่อนกันอยู่แล้วยังคุยได้ตามปกติ ส่วนคนใหม่ที่อยากเพิ่ม ให้เราเป็นฝ่ายเพิ่มเขาเอง หรือให้เขาสแกนคิวอาร์โค้ดของเราต่อหน้า วิธีนี้ทำให้เราเลือกได้ว่าจะให้ใครเข้ามาในรายชื่อเพื่อน

เปิดปฏิเสธการรับข้อความแล้ว จะพลาดข้อความสำคัญไหม

อาจพลาดข้อความจากคนที่ยังไม่ได้เป็นเพื่อน เช่น ร้านค้าหรือคนที่เพิ่งรู้จัก ถ้าต้องติดต่อใครใหม่ ให้เพิ่มเพื่อนเขาก่อนแล้วค่อยคุย สำหรับผู้สูงอายุที่ไม่ค่อยคุยกับคนใหม่ การเปิดไว้ตลอดมักคุ้มกว่า

Letter Sealing ต้องเปิดเองไหม

ตามที่ LINE ประเทศไทยชี้แจง Letter Sealing เป็นการเข้ารหัสแบบต้นทางถึงปลายทาง และใช้กับทุกแชทโดยอัตโนมัติเมื่อใช้แอปเวอร์ชันล่าสุด สิ่งที่ควรทำคืออัปเดตแอปให้ใหม่เสมอ และอย่าทำตามคลิปที่แนะนำให้ปิด

บัญชีทางการที่มีโล่ เชื่อได้ทั้งหมดไหม

โล่บอกว่าบัญชีผ่านการตรวจสอบจาก LINE แต่ไม่ได้รับประกันว่าทุกข้อความปลอดภัย และบัญชีที่ไม่มีโล่ก็ไม่ได้ปลอมเสมอไป ให้ดูช่องทางที่เราได้บัญชีมา ถ้าเพิ่มจากลิงก์ในเว็บไซต์ทางการเองจะปลอดภัยกว่าบัญชีที่ทักเข้ามาหาเรา

มีคนแปลกหน้าดึงเข้ากลุ่ม LINE ต้องทำอย่างไร

อย่ากดลิงก์หรือโอนเงินตามที่คนในกลุ่มชวน ให้ออกจากกลุ่ม แล้วรายงานกลุ่มผ่านเมนูในแอป ถ้ามีคนในกลุ่มทักส่วนตัวต่อ ให้บล็อกและรายงานบัญชีนั้นด้วย

ถ้าเผลอบอกรหัสยืนยันให้คนอื่นไปแล้ว ต้องทำอะไรก่อน

เปิด LINE ตรวจอุปกรณ์ที่ล็อกอินอยู่ ออกจากระบบอุปกรณ์ที่ไม่รู้จัก เปลี่ยนรหัสผ่าน และแจ้งเพื่อนในรายชื่อว่าอย่าโอนเงินตามข้อความจากบัญชีเราช่วงนี้ ถ้าเข้าบัญชีไม่ได้แล้ว ให้ติดต่อ LINE ผ่านหน้าศูนย์ช่วยเหลือทันที
