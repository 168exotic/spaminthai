## Short description (คำอธิบายสั้น) — สูงสุด 80 ตัวอักษร
```
เช็คเบอร์ใคร บล็อกแก๊งคอลเซ็นเตอร์และ SMS สแปม ฟรี ไม่ต้องสมัคร ฐานข้อมูลคนไทย
```
> ~78 ตัวอักษร

## Full description (คำอธิบายเต็ม) — สูงสุด 4000 ตัวอักษร
```
เบอร์แปลกโทรมา? SMS หลอกลวงเด้งเข้ามารัว ๆ? SpamInThai ช่วยคุณรู้ทันมิจฉาชีพก่อนเสียเงิน

📞 เช็คเบอร์ใครโทรมา — ฟรี
พิมพ์เบอร์ที่โทรเข้ามา รู้ทันทีว่าถูกคนไทยรายงานว่าเป็นแก๊งคอลเซ็นเตอร์ มิจฉาชีพ หรือสแปมกี่ครั้ง ใช้ฐานข้อมูลเดียวกับเว็บ spaminthai.com

🛡️ บล็อกสายมิจฉาชีพอัตโนมัติ
เปิดใช้แล้วแอปจะช่วยกรองสายจากเบอร์ที่ชุมชนรายงาน บล็อกได้ทั้งเบอร์เดี่ยวและทั้งช่วงเบอร์ (เช่น เบอร์ขึ้นต้น 065, +697)

📩 กรอง SMS สแปม (เบต้า) — เป็นส่วนตัว
ฟีเจอร์ใหม่! ตรวจจับ SMS สแปมจาก "การแจ้งเตือน" แล้วปิดการแจ้งเตือนที่เป็นสแปมให้อัตโนมัติ
• ไม่อ่านกล่องข้อความ ไม่เก็บ ไม่ส่งเนื้อหา SMS
• ส่งเฉพาะค่าแฮช (SHA-256) เพื่อเทียบฐานข้อมูลชุมชน
• เปิดใช้เองเท่านั้น (ปิดไว้เป็นค่าเริ่มต้น) ต้องกดอนุญาตก่อน

🤝 พลังของชุมชนคนไทย
ทุกครั้งที่คุณรายงานเบอร์หรือ SMS มิจฉาชีพ คุณช่วยเตือนคนไทยอีกหลายล้านคน ยิ่งมีคนใช้ ฐานข้อมูลยิ่งแม่น

🔒 ความเป็นส่วนตัวมาก่อน
• ไม่ต้องสมัครสมาชิก ไม่ต้องล็อกอิน
• ไม่ขอสิทธิ์เข้าถึงรายชื่อผู้ติดต่อ
• ไม่เก็บตำแหน่งที่ตั้ง
• ไม่ขายข้อมูลส่วนบุคคล
• สอดคล้อง พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
อ่านนโยบาย: https://spaminthai.com/privacy

✨ ฟีเจอร์เด่น
• เช็คเบอร์ฟรี ไม่จำกัด
• บล็อกสายมิจฉาชีพจากฐานข้อมูลชุมชน
• บล็อกตามช่วงเบอร์ (prefix)
• กรอง SMS สแปม (เบต้า)
• รายงานเบอร์/SMS ได้ในแอป
• อัปเดตในแอป ไม่ต้องโหลดใหม่
• ปุ่มติดต่อ LINE Official @spaminthai

โหลดฟรีวันนี้ แล้วเช็คเบอร์ก่อนรับสายทุกครั้ง — อย่าให้มิจฉาชีพหลอกได้อีก
```
