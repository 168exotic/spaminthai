# Screenshots plan — what BOSS needs to capture

Play requires **2–8 phone screenshots**. Aim for **6**. Capture on a real phone or emulator (Pixel-class, portrait).

## Specs
- **Format:** PNG or JPEG, 24-bit, no alpha
- **Ratio:** 9:16 portrait (e.g. **1080 × 1920** or 1080 × 2340)
- **Min side ≥ 320px, max side ≤ 3840px**
- Take them in the app on a clean device (full battery/signal look is fine; hide personal info)

## Capture order (do these 6, in this order)

| # | Screen | How to get there | Framing tip |
|---|---|---|---|
| 1 | **Home / number check** | Open app → Home tab | Show the check field with a number typed and a "reported as scam" result visible. This is the hero shot. |
| 2 | **Scam call blocked** | Home → block history / a blocked-call card | Show a blocked scam number with the report count. |
| 3 | **SMS spam filter screen** | Home → SMS check (onOpenSmsCheck) | Show the manual SMS check with a "spam" verdict. Highlights the v2.0.0 feature. |
| 4 | **SMS settings (opt-in toggle)** | Settings → SMS block section | Show the toggle + "OFF by default / privacy-first" copy. Reinforces the privacy story for reviewers. |
| 5 | **Prefix / range blocking** | Settings or block-by-prefix screen | Show blocking a whole range (e.g. 065). |
| 6 | **Report a number** | Home → report / report screen | Show the in-app report flow. |

## Tips
- Keep overlay text in the **top 25%** so the app UI stays visible.
- Use brand rose **#F43F5E** for caption backgrounds/accents.
- Don't show real victims' phone numbers — use example numbers (e.g. 02-xxx, 065-xxx).
- First 2 screenshots matter most (shown in search results) — make #1 and #2 the strongest.
